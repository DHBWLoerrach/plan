# Der Vorlesungskalender bleibt eine externe Lesesicht

Der Vorlesungskalender wird für interne, zur systemweiten Kurseinsicht berechtigte Konten auf der bestehenden Kursseite dargestellt. Seine Kalendertermine werden bei Bedarf aus dem DHBW-Kalendersystem gelesen und weder in den Planungsstand übernommen noch von der Veröffentlichung des Kurses abhängig gemacht: Der externe aktuelle Lehrbetrieb und die von dieser Anwendung verantwortete Blockplanung besitzen unterschiedliche Quellen, Verbindlichkeiten und Lebenszyklen.

Eine öffentliche Anzeige ist damit nicht beschlossen. Der bisherige eigenständige Kalender war passwortgeschützt; eine Öffnung gegenüber externen Nutzenden erfordert deshalb eine eigene Freigabeentscheidung für seine Inhalte.
