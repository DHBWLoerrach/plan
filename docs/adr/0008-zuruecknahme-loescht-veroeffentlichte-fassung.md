# Zurücknahme löscht die veröffentlichte Fassung

Eine Zurücknahme löscht die veröffentlichte Fassung vollständig, weil sie weder angezeigt noch wiederhergestellt wird. Ob ein Kurs schon einmal veröffentlicht war, wird stattdessen als dauerhafter fachlicher Zustand am Kurs gespeichert; dadurch bleiben seine unveränderlichen Angaben und seine Blockplanzuordnung direkt geschützt. Ein Blockplan ohne veröffentlichte Fassung gilt als noch nie veröffentlicht, solange keiner seiner Kurse diesen Zustand trägt, andernfalls als zurückgenommen.
